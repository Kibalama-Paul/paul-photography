# Paul Photography

A modern, high-performance React portfolio and photoshoot booking web application for **Paul Photography** (Kibalama Paul), featuring:

- **Interactive 3D Flip Card Gallery**: Over 100 captures with dual front/back perspectives, category filtering, search, and full-screen lightbox.
- **CEO Portfolio**: Dynamic profile photo rotator, experience milestones, skills matrix, and the official video showreel.
- **Shoot Booking**: Direct booking form with instant WhatsApp dispatch, in-app reservation receipts, and local history.
- **Smooth Page Transitions & Animations**: Powered by Framer Motion and smooth scrolling.
- **Glassmorphism & Video Backdrops**: Frosted glass panels over video loops.

## Development

```bash
npm install
npm run dev
```

Runs on `http://0.0.0.0:3000`.
